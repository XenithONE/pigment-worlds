# PIGMENT — 絵の向こうへ

星のうねり、睡蓮の光。額縁の先に広がる4つの油彩世界を歩き、12の「色のかけら」を集める、ブラウザの小さな冒険です。

公開先：[PIGMENT](https://xenithone.github.io/pigment-worlds/) · 作品一覧：[UNFILED](https://xenithone.github.io/unfiled/)

## 4つの世界

| 世界 | 着想を得た画家 | 歩いて出会う風景 |
| --- | --- | --- |
| 星月夜の丘 | Vincent van Gogh | 群青の空、金色の星、糸杉、窓に灯りのともる村 |
| 睡蓮の庭 | Claude Monet | 睡蓮の池、反った橋、柳と淡い午後の光 |
| 黄金の渓谷 | Gustav Klimtの色彩・空想の油彩 | 赤金の大樹、深緑の糸杉、厚い絵具の崖、青と黄土の川、遠い城 |
| 光の海岸 | J. M. W. Turner | 霧の海、帆船、岩の海岸と灯台 |

各世界には3つの色があります。近づいて拾うと「旅の記録」に残り、その世界の3色を揃えると短い言葉がひらきます。光る額縁から次の世界へ進むほか、「世界を選ぶ」から好きな順番で訪ねられます。色を集めなくても、すべての世界を歩けます。

## 操作

「旅をはじめる」を押して出発します。

| 操作 | PC |
| --- | --- |
| 歩く | W / A / S / D、↑ / ↓ |
| 見回す | 画面をドラッグ、Q / E、← / → |
| 少し速く歩く | Shiftを押しながら移動 |
| 近くの色を拾う・額縁をくぐる | Space / Enter、または画面の操作ボタン |
| 世界を選ぶ | M、または「世界を選ぶ」 |
| 操作と設定 | 「?」、歩行中はEscでも開く |
| メニューを閉じる | Esc、×、またはダイアログの外側をクリック |

スマートフォンでは左下の円をドラッグして歩き、画面右側をドラッグして見回します。近づいたときに表示されるボタンをタップして、色や額縁を調べます。

「音 ON」で、世界ごとに響きが変わる環境音を再生します。初期状態は音 OFFです。「写真を残す」では、メニューを含まない現在の3D風景をPNGとして保存します。

## 記録と設定

訪れた世界と集めた色は、このブラウザの `localStorage` に自動保存します。アカウントやサーバーへの進行データ送信はありません。別の端末・ブラウザとは共有されず、サイトデータを削除すると記録も消えます。位置・視線・音声・画質設定は保存対象ではありません。

「?」から描画の細かさを自動・高画質・軽量に切り替えられます。PCでは高画質、タッチ端末では自動で始まります。自動は処理が重いときに描画解像度を下げ、軽量は環境遮蔽・光のにじみ・水面の平面反射を省きます。「景色の揺らぎ」はOSの動きを減らす設定を初期値に使います。「この世界の入口へ戻る」で現在の世界の出発地点に戻れます。

## ローカルで起動

Node.js 22.12以降の22系を使用します。

```sh
npm ci
npm run dev
```

ブラウザで `http://127.0.0.1:5186/` を開きます。

```sh
npm test
npm run build
npm run preview
```

`npm test` は保存データ、12色の収集と復元、移動速度と範囲、岩・幹の衝突、急な崖でのすり抜け防止と滑り移動を確認します。描画品質・端末性能・実際の操作感はブラウザで確認してください。配布用ファイルは `dist/` に生成されます。HTMLを直接開くのではなく、開発サーバーかプレビューサーバーを使用します。

## 描画と素材

Three.js / WebGL 2でリアルタイムに描画し、Viteで静的サイトとしてビルドします。地面、近景の草花、木、橋、額縁、色のかけらはコードから生成した3D形状です。星月夜・庭園・渓谷の近景には、厚い曲面の花弁・枝分かれする茎・剣葉を持つアイリスと小花が群生します。岩は盛り重なった層と垂れる絵具で作り、岩と道には浮動小数点の高さデータから実際の凹凸を加えています。星月夜と黄金の渓谷の川沿いは、連続した顔料の崖と高い散策路です。黄金の大樹は、捻れた閉じた幹、岸に沿って垂れる根、厚い赤金の絵具が重なる樹冠としずくを持つ3D形状です。渓谷の川には青・黄土・象牙色の流れが重なり、入口からS字の曲がりが見えます。

多数の葉や筆跡は空間ごとの区画に分けてインスタンス化し、距離に応じて3段階の形状へ切り替えます。中景の交差画像平面は、閉じた厚い葉・花弁・茎を持つ3D形状へ置き換えました。近くでも横からでも厚みが残ります。

絵具の素材は物体に固定した座標で描きます。3つの非鏡映パッチを同じ重みで混ぜ、色と高さを一致させながら筆跡の規則的な反復を減らしています。浮動小数点の筆触データから法線・溝・塗膜の艶を変え、素材ごとに色の混ざり方を調整します。斜めからの光、影、GTAOによる接触部の暗がり、HDR/MSAA、控えめな筆触フィルターを組み合わせます。画面全体への粒子や凹凸の貼り付けは行いません。池と海は起伏のある顔料の流れを描き、高画質では周囲の景色を別のカメラで水面に映します。

空の絵と額縁の中の絵は、この作品のためにAI生成したオリジナル画像を中心に使っています。黄金の渓谷へ向かう額縁と作品の表紙には、実際の3D風景を写真機能で保存した画像を使っています。生成時の指示は、空については [design/asset-prompts.md](design/asset-prompts.md)、額縁の絵については [design/portal-prompts.md](design/portal-prompts.md) に記録しています。額縁の絵は次の世界を表す静止画で、歩ける3D風景とは別の素材です。画家の色彩や筆触から着想した創作空間であり、実在の絵画・場所を忠実に再現したものではありません。

文字にはFontsourceのCormorant GaramondとNoto Serif JPを使い、フォントファイルをサイトと一緒に配信します。閲覧時に外部のフォント配信サービスへ接続する必要はありません。環境音と収集時の音はWeb Audio APIで合成し、録音素材や楽曲のサンプルは使用していません。

空は背景画像です。星月夜の街並み、庭園と黄金の渓谷の遠景は、世界内に固定した曲面へ貼った静止画を距離を変えて配置しています。近景の3Dと遠景の絵画を組み合わせる方式で、遠くの描かれた建物へ入れるわけではありません。生成指示と仕様は [vista-prompts.md](design/vista-prompts.md) と [canyon-vista-prompts.md](design/canyon-vista-prompts.md)、筆触・顔料については [impasto-material-prompts.md](design/impasto-material-prompts.md) に残しています。[flora-atlas-prompts.md](design/flora-atlas-prompts.md) は、現在は使っていない旧中景植物の画像素材の制作履歴です。v15の中景植物は閉じた3D形状です。水の反射は平面を前提とした近似、絵具の流れは見た目の表現です。流体や顔料の物理シミュレーションではありません。

移動は地形の高さと範囲に沿い、大きな岩・幹を簡易的な円で避けます。全物体に精密な衝突判定があるわけではなく、屋内探索・泳ぎ・戦闘はありません。WebGL 2が必要で、描画速度と見え方は端末・ブラウザによって異なります。高画質が重い場合は自動または軽量を使ってください。

## GitHub Pagesへ公開

公開リポジトリは `XenithONE/pigment-worlds`、公開URLは `https://xenithone.github.io/pigment-worlds/` です。初回はGitHubリポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。

`.github/workflows/deploy.yml` が `main` へのpush、または手動実行で `npm ci` → `npm test` → `npm run build` を実行し、成功した `dist/` をPagesへ公開します。Viteの `base: './'` により、プロジェクトURL配下から画像とスクリプトを読み込みます。`package-lock.json` と `public/art/` の配布用画像もリポジトリに含めてください。
