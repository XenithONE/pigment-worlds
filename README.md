# PIGMENT — 絵の向こうへ

星のうねり、睡蓮の光。額縁の先に広がる4つの油彩世界を歩き、12の「色のかけら」を集める、ブラウザの小さな冒険です。

公開先：[PIGMENT](https://xenithone.github.io/pigment-worlds/) · 作品一覧：[UNFILED](https://xenithone.github.io/unfiled/)

## 4つの世界

| 世界 | 着想を得た画家 | 歩いて出会う風景 |
| --- | --- | --- |
| 星月夜の丘 | Vincent van Gogh | 群青の空、金色の星、糸杉、窓に灯りのともる村 |
| 睡蓮の庭 | Claude Monet | 睡蓮の池、反った橋、柳と淡い午後の光 |
| 黄金の花野 | Gustav Klimt | 金色の葉、白樺、花々に散りばめた装飾 |
| 光の海岸 | J. M. W. Turner | 霧の海、帆船、岩の海岸と灯台 |

各世界には3つの色があります。近づいて拾うと「旅の記録」に残り、その世界の3色を揃えると短い言葉がひらきます。光る額縁から次の世界へ進むほか、「世界を選ぶ」から好きな順番で訪ねられます。色を集めなくても、すべての世界を歩けます。

## 操作

「旅をはじめる」を押して出発します。

| 操作 | PC |
| --- | --- |
| 歩く | W / A / S / D、↑ / ↓ |
| 見回す | 画面をドラッグ、Q / E、← / → |
| 少し速く歩く | Shiftを押しながら移動 |
| 近くの色を拾う・額縁をくぐる | Space / Enter、または画面の操作ボタン |
| 世界を選ぶ | M、または「世界を選ぶ」 |
| 操作と設定 | 「?」、歩行中はEscでも開く |
| メニューを閉じる | Esc、×、またはダイアログの外側をクリック |

スマートフォンでは左下の円をドラッグして歩き、画面右側をドラッグして見回します。近づいたときに表示されるボタンをタップして、色や額縁を調べます。

「音 ON」で、世界ごとに響きが変わる環境音を再生します。初期状態は音 OFFです。「写真を残す」では、メニューを含まない現在の3D風景をPNGとして保存します。

## 記録と設定

訪れた世界と集めた色は、このブラウザの `localStorage` に自動保存します。アカウントやサーバーへの進行データ送信はありません。別の端末・ブラウザとは共有されず、サイトデータを削除すると記録も消えます。位置・視線・音声・画質設定は保存対象ではありません。

「?」から描画の細かさを自動・高画質・軽量に切り替えられます。自動は処理が重いときに描画解像度を下げ、軽量は光のにじみも抑えます。「景色の揺らぎ」はOSの動きを減らす設定を初期値に使います。「この世界の入口へ戻る」で現在の世界の出発地点に戻れます。

## ローカルで起動

Node.js 22.12以降の22系を使用します。

```sh
npm ci
npm run dev
```

ブラウザで `http://127.0.0.1:5186/` を開きます。

```sh
npm test
npm run build
npm run preview
```

`npm test` は保存データの検証、12色の収集と復元、移動速度と移動範囲を確認します。描画品質・端末性能・実際の操作感はブラウザで確認してください。配布用ファイルは `dist/` に生成されます。HTMLを直接開くのではなく、開発サーバーかプレビューサーバーを使用します。

## 描画と素材

Three.js / WebGL 2でリアルタイムに描画し、Viteで静的サイトとしてビルドします。地面、草花、木、橋、建物、額縁、色のかけらはコードから生成した3D形状です。葉、花びら、筆跡には側面と端面を持つ閉じた立体を使い、絵具を盛ったような厚みをつけています。地面や樹皮のテクスチャもプログラムで生成しています。

多数の葉や筆跡は空間ごとの小さな区画に分けてインスタンス化し、カメラからの距離に応じて3段階の形状へ切り替えます。近くでは厚みを細かく描き、遠くでは形状を簡略化するLODです。画質設定と端末に応じて切り替え距離も変わります。描画後のシェーダーで輪郭に沿って色のまとまりを整え、絵具の凹凸に似た明暗とキャンバスの粒子を加えます。水面の揺らぎと光のにじみを重ねて油彩の雰囲気をつくっています。

空の絵と額縁の中の絵は、この作品のためにAI生成したオリジナル画像です。生成時の指示は、空については [design/asset-prompts.md](design/asset-prompts.md)、額縁の絵については [design/portal-prompts.md](design/portal-prompts.md) に記録しています。額縁の絵は次の世界を表す静止画で、歩ける3D風景とは別の素材です。画家の色彩や筆触から着想した創作空間であり、実在の絵画・場所を忠実に再現したものではありません。

文字にはFontsourceのCormorant GaramondとNoto Serif JPを使い、フォントファイルをサイトと一緒に配信します。閲覧時に外部のフォント配信サービスへ接続する必要はありません。環境音と収集時の音はWeb Audio APIで合成し、録音素材や楽曲のサンプルは使用していません。

空は背景用の画像です。水面の反射は絵画的なシェーダー表現で、物理的に正確な鏡面反射ではありません。移動は地形の高さと範囲に沿った簡易方式で、木や建物など全物体との衝突判定、屋内探索、泳ぎ、戦闘は実装していません。WebGL 2が必要で、描画速度と見え方は端末・ブラウザによって異なります。

## GitHub Pagesへ公開

公開リポジトリは `XenithONE/pigment-worlds`、公開URLは `https://xenithone.github.io/pigment-worlds/` です。初回はGitHubリポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。

`.github/workflows/deploy.yml` が `main` へのpush、または手動実行で `npm ci` → `npm test` → `npm run build` を実行し、成功した `dist/` をPagesへ公開します。Viteの `base: './'` により、プロジェクトURL配下から画像とスクリプトを読み込みます。`package-lock.json` と `public/art/` の配布用画像もリポジトリに含めてください。
